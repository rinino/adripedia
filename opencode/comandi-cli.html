Comandi CLI

Tutto ciò che puoi lanciare da terminale con opencode. Ogni comando accetta --help per l'elenco completo dei flag.

Sintassi

opencode <sottocomando> [flag] [directory]

Flag principali

FlagSignificato
--standaloneUsa un server privato invece del servizio condiviso.
--server <url>Collegati a un server specifico.
--autoApprova automaticamente i permessi non esplicitamente negati.
--continue, -cContinua l'ultima sessione.
--session, -s <id>Continua una sessione specifica, o creala se non esiste.
--prompt <testo>Prompt iniziale.

Flag globali

FlagSignificato
--help, -hMostra l'aiuto.
--version, -vMostra la versione.
--wizardAvvia la modalità guidata per un comando.
--completions <shell>Stampa lo script di completamento: bash, zsh, fish, powershell, sh, pwsh.
--log-level <livello>all, trace, debug, info, warn, error, fatal, none.
--print-logsStampa i log su stderr (i log del server richiedono --standalone).

Sottocomandi

ComandoCosa fa
opencodeApre la TUI nella cartella corrente (o in quella indicata).
runEsegue un prompt e stampa la risposta, senza TUI.
miniInterfaccia interattiva minimale.
serveAvvia il server API e web V2.
pairStampa link monouso per collegare browser o app.
sessionGestisce le sessioni.
authGestisce integrazioni e credenziali.
modelsElenca i modelli disponibili.
mcpGestisce i server MCP.
pluginGestisce i plugin.
statsStatistiche d'uso condivisibili.
serviceGestisce il server in background.
reloadRicarica la configurazione.
apiChiama l'API del server in esecuzione.
acpAvvia un server Agent Client Protocol.
debugStrumenti di diagnostica.
upgrade, updateAggiorna OpenCode.
uninstallDisinstalla OpenCode, conservando dati e configurazione.

run

Invia un messaggio e stampa la risposta. Pensato per script e CI.

opencode run "Spiega questo repository"

opencode run --model anthropic/claude-sonnet-5-5 "Rifattorizza parseToken"

opencode run --continue "Ora gestisci il caso scaduto"

opencode run --agent build "Correggi il test che fallisce"

opencode run --format json "Elenca i commenti TODO"

opencode run --file src/server.ts --file src/client.ts "Cerca bug"
FlagSignificato
--continue, -cContinua l'ultima sessione.
--session, -sContinua una sessione specifica.
--forkEsegue un fork della sessione prima di continuare.
--model, -mModello nel formato provider/modello#variante.
--agentAgente da usare.
--formatdefault o json.
--file, -fAllega un file al messaggio.
--titleTitolo della sessione.
--thinkingMostra i blocchi di ragionamento.
--autoApprova i permessi non esplicitamente negati.

mini

opencode mini
opencode mini --continue
opencode mini --model anthropic/claude-sonnet-5-5 --prompt "Riassumi il repository"
opencode mini --session ses_4f2a1c

Flag: --continue, --session, --fork, --replay, --replay-limit, --model, --agent, --prompt.

session

opencode session list
opencode session list --max-count 20 --format json
opencode session delete ses_9c1b08
opencode session export ses_4f2a1c
opencode session export ses_4f2a1c --sanitize
opencode session import session.json
opencode session import session.json --directory ~/code/progetto

auth

opencode auth list
opencode auth list --format json
opencode auth login anthropic
opencode auth login anthropic --method key
opencode auth logout anthropic work
opencode auth switch anthropic work
opencode auth export anthropic > credentials.json
opencode auth import credentials.json
auth export include i segreti. Tratta il file come una password.

models

opencode models

mcp

opencode mcp list
opencode mcp add context7 --url https://mcp.context7.com/mcp
opencode mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
opencode mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
opencode mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
opencode mcp auth sentry
opencode mcp logout sentry

plugin

opencode plugin list
opencode plugin list --builtin
opencode plugin add @esempio/opencode-tui
opencode plugin check
opencode plugin update
opencode plugin remove @esempio/opencode-tui

stats

opencode stats
opencode stats --days 7
opencode stats --models
opencode stats --cost
opencode stats --json
opencode stats --project .

Altri flag: --year, --all, --tools, --full, --limit.

serve

opencode serve
opencode serve --hostname 0.0.0.0 --port 4096
opencode serve --cors https://app.example.com

pair

opencode pair
opencode pair --url https://dev.example.com
opencode pair --remote
opencode pair --remote --yes
--remote espone il server a Internet tramite OpenTunnel. La prima volta chiede conferma.

service

opencode service start
opencode service restart
opencode service status
opencode service stop
opencode service get hostname
opencode service set hostname 0.0.0.0
opencode service set cors https://app.example.com
opencode service set env OPENCODE_LOG_LEVEL DEBUG
opencode service unset hostname

reload

opencode reload

Ricarica la configurazione senza riavviare il server. Le sessioni in corso continuano con i nuovi servizi al confine del passo successivo.

api

opencode api GET /api/session
opencode api session.list --param limit=10
opencode api session.create --data '{"title": "Nuova sessione"}'
opencode api GET /api/session -H "accept: application/json"

Flag: --data/-d, --header/-H, --param key=value. Accetta anche --standalone e --server.

acp

opencode acp
opencode acp --login

debug

opencode debug agents
opencode debug config
opencode debug heap-dump
opencode debug heap-dump --directory ./snapshots
opencode debug paths
opencode debug paths db

upgrade

opencode upgrade
opencode upgrade 2.0.21
opencode upgrade 2.0.21 --method bun

Metodi: curl, npm, pnpm, bun, yarn, vp, brew, winget.

uninstall

opencode uninstall --dry-run
opencode uninstall
opencode uninstall --force
