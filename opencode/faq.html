FAQ e problemi comuni

Le domande che tornano più spesso, con la risposta breve e il rimando alla pagina che entra nel dettaglio.

Perché non posso passare da Build a Plan?

Perché nella V2 Build e Plan sono agenti, non modalità della TUI. La vecchia scorciatoia Tab non esiste più: usa Shift+Tab, oppure Ctrl+X poi A per scegliere dalla lista.

Dettagli sugli agenti →

Shift+Tab non fa nulla

Quasi sempre è il terminale che intercetta la combinazione. Rimappa il comando agent.cycle in cli.json: 

{
  "keybinds": {
    "agent.cycle": "alt+p"
  }
}

Alt+P è libero nei default della V2. In alternativa prova F3.

Come cambio modello?

  • Ctrl+X, poi M.
  • /models.
  • F2 per ciclare i modelli usati di recente.

Cambiare agente non cambia il modello: sono selezioni separate.

Dove trovo i log?

~/.local/share/opencode/log/opencode.log

Filtra role=cli per l'avvio del client e role=server per sessioni, provider, plugin, permessi e strumenti. Per un singolo caso riproducibile, alza il livello: 

OPENCODE_LOG_LEVEL=DEBUG opencode

Su PowerShell:

$env:OPENCODE_LOG_LEVEL="DEBUG"; opencode

Ho modificato la configurazione ma non cambia nulla

Controlla di aver usato il file giusto: tema e keybind vanno in cli.json, tutto il resto in opencode.json(c). Le modifiche vengono ricaricate da sole; per forzarle: 

opencode reload

Oppure /reload nella TUI.

Come scrivo un prompt su più righe?

Shift+Enter, Ctrl+Enter, Alt+Enter o Ctrl+J.

Come annullo l'ultimo messaggio?

Ctrl+X, poi U, oppure /undo. Il prompt annullato torna nel campo, pronto da modificare. Per ripristinare: Ctrl+X, poi R, oppure /redo.

Un server MCP chiede l'autenticazione

Apri /mcps, scegli il server e accedi. Non lanciare opencode mcp auth da uno script: avvia un flusso interattivo e il link di autorizzazione può finire nascosto nell'output.

Posso usare OpenCode in CI?

Sì. Passa la chiave del provider come segreto e usa --standalone: 

opencode run --standalone --model anthropic/claude-sonnet-5-5 "Revisiona il repository"

Con --format json ottieni JSON a righe, comodo per gli script.

Come pubblico questo sito su GitHub Pages?

  1. Crea un repository su GitHub.
  2. Carica il contenuto della cartella nella radice del repository.
  3. Vai in Settings → Pages.
  4. In Source scegli Deploy from a branch.
  5. Seleziona main e / (root), poi Save.

Il file .nojekyll già presente evita che GitHub Pages ignori file o cartelle che iniziano con un underscore.

Come disinstallo senza perdere i dati?

opencode uninstall --dry-run
opencode uninstall

La disinstallazione rimuove eseguibile e cache globale, ma conserva sessioni, configurazione e stato.

Il servizio sembra bloccato

opencode service status
opencode service restart
opencode api get /api/info

Per capire se il problema è del servizio condiviso o del progetto, prova opencode --standalone.
